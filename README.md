# Bachelor-Thesis-code

This repository contains the code used to conduct the analysis of my Bachelor thesis. The code main functionalities are in terms of parsing in data from N-body or gravothermal fluid simulations and doing an analysis with them. This includes plotting, extremal value problems, construction of likelihoods as well as set ups for
dynamic nested sampling.

## Installation

Just clone the repo, ya'll know how to do it ;)
